Hi! I'm Mahalakshmi, an MS CS New Grad from Purdue University Fort Wayne (Class of 2026), building at the intersection of full-stack engineering, product thinking, and customer-facing technical work.

I'm currently preparing for new grad and entry-level roles in Software Engineering, Product Management, Customer Success Engineering, and Technical Support Engineering, starting in 2026.

## What's Inside

This site is built to work for three audiences at once:

- **For engineers:** real projects with the stack, architecture decisions, and technical depth behind each one — including a real production bug I found and fixed after shipping.
- **For product folks:** each project doubles as a case study — problem, approach, outcome — with a couple including a full mini-PRD (goals, target users, requirements, success metrics, and explicit scope boundaries).
- **For support & customer success folks:** each project also shows how I troubleshoot, communicate technical issues to non-technical stakeholders, and iterate based on direct user/customer feedback — the same skills I bring to resolving live issues and supporting end users.
